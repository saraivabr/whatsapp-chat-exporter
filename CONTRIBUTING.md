# Contributing to WhatsApp Chat Exporter

First off, thanks for taking the time to contribute! 🎉

The following is a set of guidelines for contributing to WhatsApp Chat Exporter. These are mostly guidelines, not rules. Use your best judgment, and feel free to propose changes to this document in a pull request.

## 🛠️ How to Contribute

### Reporting Bugs

- **Ensure the bug was not already reported** by searching on GitHub under [Issues](https://github.com/RezaMahdaviiDev/whatsapp-chat-exporter/issues).
- If you're unable to find an open issue addressing the problem, [open a new one](https://github.com/RezaMahdaviiDev/whatsapp-chat-exporter/issues/new).
- Include a **title and clear description**, as much relevant information as possible, and a **code sample** or an **executable test case** demonstrating the expected behavior that is not occurring.

### Suggesting Enhancements

- Open a new issue and describe your idea clearly.
- Explain why this enhancement would be useful to most users.

### Pull Requests

1. Fork the repo and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. Ensure the test suite passes.
4. Make sure your code lints.
5. Issue that pull request!

## 💻 Development Setup

1. Clone the repository
2. Run `npm install`
3. Create a `config.js` based on the example
4. Run `npm start` to test

## 📜 Style Guide

- Use **ES6+** syntax features
- Keep functions small and focused
- Add comments for complex logic
- Use meaningful variable names (English)
